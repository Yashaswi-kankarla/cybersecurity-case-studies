## Repository Overview

This repository contains three independent case studies:

### Malware Analysis
Static and dynamic analysis of suspicious Windows binaries to identify persistence mechanisms, defense-evasion techniques, command-and-control behavior, and indicators of compromise.

**Key Skills**
- Malware Analysis
- Threat Intelligence
- MITRE ATT&CK Mapping
- Digital Forensics
- Network Traffic Analysis
- IOC Development

➡️ Branch: `malware-analysis`

---

### Log Analysis
Investigation of endpoint and security logs using Splunk to identify compromised systems, reconstruct attack timelines, determine patient zero, and trace attack progression.

**Key Skills**
- SIEM Operations
- Splunk
- Threat Hunting
- Event Correlation
- Timeline Reconstruction
- Incident Investigation

➡️ Branch: `log-analysis`

---

### Audio Denoising & Transcription
Recovery of intelligible speech from noisy recordings through source separation, audio enhancement, and automated transcription techniques.

**Key Skills**
- Audio Signal Processing
- Information Extraction
- Speech Processing
- Python
- Workflow Automation
- Technical Reporting

➡️ Branch: `audio-denoising-transcription`

## About This Repository

These case studies were created as part of advanced technical assessment and learning exercises. The focus of this repository is to showcase analytical methodology, investigative workflows, documentation skills, and evidence-based reporting.

Each branch contains:
- A detailed technical report
- Investigation methodology
- Findings and analysis
- Supporting evidence and screenshots
- Conclusions and recommendations
